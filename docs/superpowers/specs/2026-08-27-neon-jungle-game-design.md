# 《霓虹丛林：雷霆行动》游戏设计规格

## 1. 目标

制作一款可直接在浏览器游玩的原创复古街机横版射击游戏。它借鉴经典跑跳射击类型的操作节奏，但不使用《魂斗罗》的角色、Logo、关卡、音乐或美术素材。完成品需要兼顾精美视觉、即时可玩性、桌面与移动端适配，并可静态部署到 Vercel。

## 2. 技术方案

采用 React、TypeScript、Vite 与 Phaser 3。React 负责启动页、HUD 外壳、暂停/结算界面和响应式布局；Phaser 负责场景、物理、碰撞、动画、粒子和音频。

选择 Phaser 而不是手写 Canvas，是因为本项目同时需要镜头跟随、精灵动画、平台碰撞、敌人 AI、弹道、Boss 状态机和移动端输入。相较 DOM 游戏，Phaser 的帧循环与碰撞模型更稳定；相较完整 3D 引擎，它的产物更轻，适合 Vercel 静态托管。

## 3. 核心体验

- 玩家可左右奔跑、跳跃、下蹲、穿越平台，并向八个方向瞄准射击。
- 基础步枪无限弹药；关卡内可拾取散射枪和脉冲枪，受伤后武器降级。
- 一条连续关卡包含雨林前线、废弃哨站、军工基地三段视觉区域。
- 敌人包括巡逻兵、飞行侦察器、固定炮塔和冲锋单位。
- 中段设置检查点；终点为拥有三个攻击阶段的机械 Boss。
- 玩家有 3 点生命值、短暂无敌帧、得分与连击系统；死亡后从检查点重生，生命耗尽显示结算页。
- 首屏提供“开始任务”、操作说明和声音开关；Esc 可暂停，R 可重新开始。
- 桌面端支持 WASD/方向键、J/空格射击、K/Shift 跳跃；移动端显示虚拟摇杆、射击和跳跃按钮。

## 4. 视觉与声音

美术方向为原创 16-bit 复古像素风：深青雨林、橙红爆炸、青蓝能量武器、紫色军工霓虹。前景植被、中景设施和远景雾林使用三层视差；角色、敌人、地形、道具、Boss、背景与特效均采用统一像素比例。

生成式美术将用于完整游戏画面概念、角色与敌人精灵、地形图块、道具、Boss 和视差背景。HUD 文字、按钮、碰撞框与游戏状态保持代码原生。声音使用 Web Audio 合成的原创短音效和节奏氛围，不引用原作音乐。

## 5. 页面与状态

1. 加载状态：显示任务徽标、资源进度和简短提示。
2. 启动页：完整场景背景、游戏标题、开始按钮、操作说明、声音开关。
3. 游戏态：顶部 HUD 展示生命、武器、得分、连击与 Boss 血条；画面保持 16:9，并对窄屏等比缩放。
4. 暂停态：半透明菜单，可继续、重新开始或返回标题。
5. 成功/失败态：显示用时、得分、最高连击和重新挑战按钮。

## 6. 代码边界

- `src/game/config.ts`：Phaser 配置与画布缩放。
- `src/game/scenes/`：加载、标题、关卡、结算场景。
- `src/game/entities/`：玩家、敌人、Boss、投射物和拾取物。
- `src/game/systems/`：输入、武器、音频、检查点和关卡数据。
- `src/ui/`：React 外壳、HUD、移动端控制和覆盖层。
- `src/assets/`：生成并压缩后的 WebP/PNG 资源。

游戏状态通过一个轻量事件总线同步给 React HUD；渲染与物理状态留在 Phaser 内部，避免每帧触发 React 渲染。

## 7. 错误与性能策略

- 资源加载失败时使用同风格的最小后备纹理，并显示可重试提示，不能停在空白页。
- 对象池复用子弹、爆炸和粒子；限制同时在场的敌人与投射物数量。
- 目标为桌面端 60 FPS、主流移动端稳定 30 FPS；资源总量控制在合理范围并使用懒加载。
- 音频只在首次用户交互后启动，遵守浏览器自动播放限制。
- 支持 `prefers-reduced-motion`，减少闪屏、镜头震动和粒子数量。

## 8. 验收标准

- 本地 `npm run build` 与自动化测试通过。
- 从点击开始到完成关卡的主流程可实际游玩；移动、跳跃、八向射击、换武器、受伤、检查点、Boss、胜负与重开均有效。
- 桌面 1440×900、常见笔记本视口和移动端 390×844 无溢出或不可用控件。
- 浏览器无未处理异常，核心资源无 404。
- 实际截图与批准的概念图在布局、色彩、资产、HUD、字体和画面密度上保持一致。
- GitHub 留存完整源码与 README；Vercel 生产部署状态为 READY，并完成线上首屏与核心交互验证。

## 9. 明确不做

首版不包含双人模式、联网排行、多关卡选择、账号系统、付费功能或服务端存档。这些功能不会阻塞完整的一关式街机体验。
